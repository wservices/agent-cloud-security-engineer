# 0.1.0 — initial scaffold

Initial scaffold release of the `cloud-security-engineer` Hermes profile.

- Role definition (`ROLE.md`), persona (`SOUL.md`), and distribution manifest —
  strictly read-only / advisory posture across AWS, Azure, and GCP; escalates to
  the Security Team Lead.
- Six bundled skills: `cloud-posture-review-cspm`, `iam-least-privilege-review`,
  `cloud-network-and-exposure-review`, `secrets-and-key-management-review`,
  `cloud-benchmark-compliance`, and `cloud-security-reporting`.
- Read-only cloud credentials declared in `env_requires` (AWS ViewOnly/
  SecurityAudit, Azure Reader, GCP Viewer); `docs/ENVIRONMENT.md` generated from
  the manifest.
- apt tool layer (`awscli`, `jq`, `ripgrep`); non-apt cloud CLIs and scanners
  (`az`, `gcloud`, `prowler`, `scoutsuite`) documented in `tools/README.md`.
- Offline scaffold pytest suite and GitLab CI include.
